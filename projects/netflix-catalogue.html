The reporting problem

Content metadata mixes movies and TV series, and multi-country fields complicate geographical comparisons. The dashboard needs to distinguish runtime from TV-season counts and keep missing values visible.

Approach

  1. Built calculated fields for movie-only runtime and broad genre classification, excluding TV-season values from runtime analysis.
  2. Compared country contributions, runtime by genre, genre composition and the distribution of content ratings.
  3. Added release-year and director filters and published the interactive dashboard on Tableau Public.

FINDING → NEXT ACTION

The source shows substantial catalogue contributions from the United States and India, while genre composition and content-rating patterns vary. The dashboard supports exploration of these differences, not conclusions about viewership or commercial performance.

Use the filters to investigate content mix. For a more precise country-level analysis, first normalise multi-country and multi-genre fields rather than treating combined strings as single countries or genres.

Verification

The local workbook and case-study notes define the source as 8,780 titles and document the movie-only runtime calculation. The published Tableau Public dashboard is the interactive deliverable; this refresh adds a clear project page and direct navigation.

Scope and limitations

A historical public dataset, not Netflix's current live catalogue. Multi-country strings remain as supplied; missing country and director values are retained. No viewing, revenue, licensing-cost or engagement data is available.
