# Erochukwu Amajoyi — Data and Automation Portfolio

Personal portfolio covering supply-chain reporting, inventory planning and data-quality automation.

## Projects

- **Supplier performance — Power BI:** a two-page report with a four-table model and eight DAX measures across 1,500 purchase-order lines.
- **Inventory health — Excel:** an 80-item replenishment model using exact-match lookups, validation controls, formula summaries and a native chart.
- **Reporting controls — Python:** purchase-order and BOM validation, diagnostic outputs, HTML/JSON reports and 12 tests.

Open `index.html` to review the portfolio locally. Project files and the full source/data bundle are in `files/`.

## Scope

The supply-chain data is fictional. This is independent personal work, not a project commissioned by an employer. ERP/MRP structures are simulated; no live SAP access is claimed. Power Automate delivery is a proposed workflow, not a deployed flow. No realised savings are claimed.

The website's charts are web summaries of project data, not screenshots or embedded Power BI visuals. The actual Power BI and Excel files are downloadable. Definitions, assumptions and verification limits are documented on the site and in the project bundle.

## Hosting

Static HTML, CSS and JavaScript, published from the root of the `main` branch using GitHub Pages. `.nojekyll` keeps the site buildless. The public repository intentionally excludes CV files and personal contact details.
